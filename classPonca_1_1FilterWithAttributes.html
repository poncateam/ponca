Detailed Description

template<class _DataPoint, typename DataType, typename NeighborFilter, auto DataConverter>
class Ponca::FilterWithAttributes< _DataPoint, DataType, NeighborFilter, DataConverter >

This class extends a NeighborFilter class to also store additional data, for use outside the scope of this class.

Template Parameters
DataTypeThe type of data to store along the filter
NeighborFilterAny NeighborFilter type (e.g., NoWeightFilter or DistWeightFilter<ConstantWeightKernel>)
DataConverterA function that construct a DataType from the DataPoint
