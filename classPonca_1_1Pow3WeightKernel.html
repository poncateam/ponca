Detailed Description

template<typename _Scalar>
class Ponca::Pow3WeightKernel< _Scalar >

Non-compact interpolation kernel used by interpolary surface reconstruction schemes (e.g.

RBF)

Note
This is not a decreasing weight function, thus the kernel should not be used to weight neighbors in standard Basket fitting, e.g. using DistWeightFunc.
