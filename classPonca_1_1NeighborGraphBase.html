Build a neighbor graph by connecting all points using Euclidean range queries: two points.

\[\mathbf{p,q}\]

are connected if

\[\mathbf{p}-\mathbf{q}<\text{range}\]

Note
Each point might have a different number of neighbors
Empty neighborhood are not checked
Parameters
_kdtreeReference to the KdTree
rangeDistance threshold used to connect points
Warning
Stores a const reference to kdtree.point_data()
KdTreeTraits compatibility is checked with static assertion
