Detailed Description

template<Ponca::StringLiteral _Name, class Type>
struct Ponca::FactoryEntry< _Name, Type >

Factory entry.

This class stores as compile time constant:

  • A name of the entry (with string)
  • A type, presumably a ComputeObject but this is not mandatory
  • An identifier

Any instance of this class stores an instance of the associated type.
