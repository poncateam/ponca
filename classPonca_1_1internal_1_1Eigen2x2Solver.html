Detailed Description

template<typename Scalar>
class Ponca::internal::Eigen2x2Solver< Scalar >

Closed-form eigen decomposition of a 2x2 matrix with real eigenvalues, not necessarily symmetric.

Drop-in replacement for Eigen::SelfAdjointEigenSolver<Matrix2>::computeDirect but for cases where the matrix is not symmetric. Unlike other eigen slovers, this code works within cuda kernels.
