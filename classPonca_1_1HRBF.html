Detailed Description

template<class P, typename _WeightKernel = Pow3WeightKernel<typename P::Scalar>>
requires ProvidesNormal<P>
class Ponca::HRBF< P, _WeightKernel >

Hermite Radial Basis Function (HRBF) implicit surface interpolation.

Builds a scalar field \( f \) that interpolates both the positions and the normals of a set of oriented points.

Template Parameters
PPoint type, must provide normals (see ProvidesNormal)
_WeightKernelInterpolation kernel. Defaults to Pow3WeightKernel.
